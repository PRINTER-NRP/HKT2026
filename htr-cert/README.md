# เว็บค้นหาเกียรติบัตร — SUT-Digital Hackathon : Hack the Research

เว็บหน้าเดียว ให้นักศึกษาพิมพ์รหัสตัวเองแล้วดาวน์โหลดเกียรติบัตรได้
ไม่ต้องใช้เซิร์ฟเวอร์ ไม่ต้องใช้ฐานข้อมูล ไม่มีค่าใช้จ่าย

กิจกรรม 1-4 มิถุนายน 2569 · รายชื่อผู้มีสิทธิ์ 330 คน · ไฟล์เกียรติบัตรพร้อมแล้ว 328 ใบ

---

## อ่านก่อน — ไฟล์แบ่งเป็น 5 ชุด

GitHub อัปโหลดผ่านเว็บได้ครั้งละไม่เกิน 100 ไฟล์ ผมเลยแบ่งรูปไว้ให้ชุดละ 82 ใบ

```
HTR-1-site.zip     ->  index.html, data.json, assets/, README.md
HTR-2-certs.zip    ->  โฟลเดอร์ certs (82 ไฟล์)
HTR-3-certs.zip    ->  โฟลเดอร์ certs (82 ไฟล์)
HTR-4-certs.zip    ->  โฟลเดอร์ certs (82 ไฟล์)
HTR-5-certs.zip    ->  โฟลเดอร์ certs (82 ไฟล์)
```

แตกไฟล์ที่ 2-5 **คนละที่กัน** (ไม่งั้นโฟลเดอร์ `certs` ชื่อซ้ำจะทับกันเอง)
แล้วลากเข้า GitHub ทีละชุด ไฟล์จะไปรวมกันในโฟลเดอร์ `certs` เดียวเอง เพราะชื่อไฟล์ไม่ซ้ำ

เสร็จแล้วในโฟลเดอร์ `certs` ต้องมี **328 ไฟล์**

## โครงสร้างไฟล์

```
index.html          หน้าเว็บทั้งหมด (HTML + CSS + JavaScript ในไฟล์เดียว)
data.json           รายชื่อ 330 คน
assets/bg.jpg       ภาพพื้นหลังจาก THEME
certs/              รูปเกียรติบัตร 328 ใบ ตั้งชื่อตามรหัส นศ.
```

**ห้ามเปลี่ยนชื่อโฟลเดอร์ `certs` และ `assets`** เพราะโค้ดอ้างอิงชื่อนี้อยู่
ชื่อไฟล์รูปต้องเป็น `รหัสนักศึกษา.jpg` เช่น `B6501631.jpg`

## 2 คนที่ยังไม่มีไฟล์เกียรติบัตร

| รหัส | ชื่อ |
|---|---|
| B6501617 | SUPHANAT SOMBATKHAM |
| B6728182 | INTHIRAPORN BUNLOED |

ตอนนี้ถ้าสองคนนี้ค้นหา เว็บจะขึ้นว่า **"ยังไม่มีไฟล์เกียรติบัตรของคุณ — ชื่ออยู่ในรายชื่อผู้มีสิทธิ์ แต่ไฟล์ยังอยู่ระหว่างจัดทำ"**
ไม่ได้ขึ้นว่าไม่พบรหัส เพื่อไม่ให้นักศึกษาเข้าใจผิดว่าตัวเองไม่มีสิทธิ์

**พอทำไฟล์เสร็จแล้ว** ทำ 2 อย่างนี้
1. วางไฟล์ `B6501617.jpg` และ `B6728182.jpg` ลงโฟลเดอร์ `certs/`
2. เปิด `data.json` ลบ `,"p":1` ออกจากสองบรรทัดนั้น

## เอาขึ้นเว็บด้วย GitHub Pages

**1. สร้าง repository ใหม่**
กดปุ่ม **+** มุมขวาบน → **New repository** → ตั้งชื่อ เช่น `htr-cert` → เลือก **Public** → **Create repository**

**2. อัปโหลด**
กด **uploading an existing file** แล้วลากไฟล์เข้าไปทีละชุดตามหัวข้อด้านบน กด **Commit changes** ทุกรอบ

**3. เปิด GitHub Pages**
แท็บ **Settings** → เมนูซ้าย **Pages** → Source เลือก **Deploy from a branch** → Branch `main` / `(root)` → **Save**

รอ 1-2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/htr-cert/`

**4. ตรวจก่อนส่งจริง**
- พิมพ์ `B6501631` ต้องขึ้น JESSADA PAKONPHAKDI พร้อมรูป
- กดปุ่มบันทึก ต้องได้ไฟล์ `Certificate_HackTheResearch_B6501631.jpg`
- พิมพ์ `B6501617` ต้องขึ้นข้อความว่ายังไม่มีไฟล์
- พิมพ์รหัสมั่ว ๆ ต้องขึ้นว่าไม่พบ

## ทดสอบบนเครื่องตัวเองก่อน

ดับเบิลคลิก `index.html` เฉย ๆ **จะใช้ไม่ได้** เพราะเบราว์เซอร์ไม่ยอมให้อ่าน `data.json`
เปิด Terminal มาที่โฟลเดอร์นี้แล้วพิมพ์

```
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000

---

## แก้ข้อมูลทีหลัง

**รายชื่อ** — แก้ที่ `data.json` รูปแบบ

```json
[{"i":"B6501631","n":"JESSADA PAKONPHAKDI"}]
```

- `i` = รหัสนักศึกษา (ต้องตรงกับชื่อไฟล์ใน `certs/`)
- `n` = ชื่อ-นามสกุลที่จะโชว์บนเว็บ
- `"p":1` = ใส่เมื่อยังไม่มีไฟล์เกียรติบัตร (ลบออกเมื่อมีไฟล์แล้ว)

**พื้นหลัง** — เอาไฟล์ใหม่ทับ `assets/bg.jpg` (ต้องเป็น 16:9)
ตำแหน่งช่องค้นหาอยู่ที่ `left:5.7%` `top:56%` แก้ได้ที่คลาส `.finder` ใน `index.html`

## ความปลอดภัย

เว็บค้นด้วยรหัสนักศึกษาอย่างเดียว ใครรู้รหัสคนอื่นก็เปิดดูได้ และไฟล์ใน `certs/` เข้าถึงตรงได้ถ้ารู้ URL
สำหรับเกียรติบัตรกิจกรรมถือว่ารับได้ ถ้าอยากกันเพิ่มให้เพิ่มช่องกรอก 3 ตัวแรกของชื่อคู่กับรหัส
